Discord Developer Setup Guide

How to link your custom Discord application

1

Create a Discord Application

Navigate to the Discord Developer Portal. Click New Application at the top right and enter a name (e.g., "Event Helper Bot").

2

Retrieve Application Credentials

In your new app's sidebar, click OAuth2. Locate the CLIENT ID and copy it to your clipboard.

3

Add Redirect Redirect URIs

Under OAuth2 Settings, click Add Redirect. Add the full URL where this web app is hosted (e.g., current page URL). Save your changes in Discord!

4

Paste Config into App

Click the gear icon ⚙️ in the header of this app and paste your Client ID and Redirect URI.
